# NEXUS app

Expo (React Native) guest app for the NEXUS proof of concept.

Setup, run order and troubleshooting are in the [root README](../README.md).

Quick start, from this folder:

```powershell
copy .env.example .env.local
# edit .env.local and set EXPO_PUBLIC_API_URL (see the root README for which URL to use)
npm install
npx expo start -c
```
